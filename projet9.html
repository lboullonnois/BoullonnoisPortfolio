Application communicante

Description du Projet

Ce projet consistait à développer une application complète pour détecter les vulnérabilités d'un réseau. L'écosystème comprend une interface web, un serveur centralisé et une application Android permettant de visualiser les alertes en temps réel, avec une communication fluide assurée par des flux de données JSON.

Ce que j'ai appris

  • Développement Full-Stack : Maîtrise de l'interaction entre différentes technologies (Java, SQL, Web, Android).
  • Gestion de Projet Agile : Utilisation de GitHub pour le versioning, définition d'un tableau RACI et travail en mode client-fournisseur.
  • Scans de Sécurité : Automatisation et intégration des outils Nmap et Dirb pour l'analyse des surfaces d'attaque.

Les outils utilisés

  • Java
  • Android Studio
  • SQL
  • JSON
  • Nmap
  • Dirb
  • GitHub
