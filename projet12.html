Script Powershell

Description du Projet

L'objectif de ce projet est de concevoir un script PowerShell modulaire et automatisé permettant de collecter, formater et exporter l'inventaire complet (matériel et logiciel) d'un parc informatique vers un fichier CSV.

Ce que j'ai appris

  • Scripting PowerShell : Maîtrise des structures de contrôle, des variables et de la manipulation d'objets pour l'automatisation de tâches système.
  • Gestion des données : Filtrage des propriétés spécifiques, formatage des données brutes et export structuré au format CSV pour exploitation ultérieure.
  • Modularité et Maintenance : Organisation du code en fonctions réutilisables et implémentation de la gestion d'erreurs pour assurer la fiabilité du script.

Les outils utilisés

  • VS Code
  • Active Directory Server
  • Shell Powershell
